Welcome to the perforation and lysis data repository.

Raw data is stored in the directories named 'trench_<trench_number>_images'.

All data analysis and code is stored in the zip file 'analysis.zip'.

To verify the integrity of your download, checksums (a SHA256 hash of each file) are provided. 
You can verify the data integrity by running the script '00_verify_checksums.py' with Python. 
If any of the files are corrupted, further checksums are provided within each zipped file to allow
you to pinpoint source of the corruption. 

A further readme is provided in the analysis folder which explains the structure of the analysis.
